## 다음 작업: 비정면 카메라 마운트 대응 (캘리브레이션)

### 배경

타깃 설치 시나리오:
- **차량 2열 어시스트 그립에 카메라 부착**
- 카메라가 아래 방향으로 아이(카시트)를 촬영
- 즉, 항상 머리 위쪽·비스듬한 각도에서 얼굴을 봄

이 상태에서 현재 코드는 **정면 카메라를 가정**하므로:
- 정상 자세인데도 pitch가 항상 큰 값으로 편향됨 → 거짓 HEAD BENT
- Yaw / Roll도 약간 편향 가능

### 해결책: 캘리브레이션 (수동 'c' 키)

**원리**:
```
캘리브레이션 시점:
    R_cal, _ = cv2.Rodrigues(rvec_at_neutral)   # 기준 회전 행렬 저장

매 프레임:
    R_curr, _ = cv2.Rodrigues(rvec_now)
    R_rel = R_cal.T @ R_curr                    # 기준 회전 제거
    pitch_rel, yaw_rel, roll_rel = decompose_euler(R_rel)
```

→ 이러면 캘리브레이션 자세 대비 "얼마나 기울었는가"만 측정됨. 카메라 마운트 각도와 무관해짐.
